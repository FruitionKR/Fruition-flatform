# AI 에이전트 자동 승인: 삭제·외부 공유 분류 보류

작성일: 2026-11-02. 결정을 미루고 현재 동작을 유지한다. 추적은 이슈 #90의 "F. 2026-11-02 결정을 미룬 UX 항목".

## 배경

외부 검토 의견:

> 문서 삭제·외부 공유 등 고위험 LLM 작업 시 사용자 승인을 받게 한 것은 타당하나 편의성을 고려하여 자동화된 판단이 가능하도록 하면 좋을 것임.

## 현재 에이전트 승인 흐름

1. 에이전트가 실행 계획을 만든다.
2. 실행은 `awaiting_approval` 상태로 멈춘다.
3. 사용자가 승인하면 `POST /api/workspaces/{ws}/agent/runs/{id}/approve`가 호출된다.
4. 실행 시 도구마다 권한을 다시 검사한다.

## 에이전트 도구

에이전트가 쓸 수 있는 도구는 7개다.

- `create_folder`, `rename_folder`, `move_folder`, `move_document`, `rename_document`, `create_document`, `apply_document_edit`

삭제·외부 공유 도구는 없다. `delete_document`·`delete_folder`는 실행을 취소할 때 만든 것을 되돌리는 용도로만 쓴다.

동작:

- 설정 › 디스플레이 설정 › "AI 에이전트 자동 승인".
- 분류는 `organize`(폴더 정리: 생성·이동·이름 변경)와 `content_edit`(문서 편집·생성) 두 가지. 기본은 꺼짐.
- 서버가 실행 시점의 설정과 사용자의 실제 편집 권한으로 자동 승인 여부를 판단한다.
- 경고가 있거나, 권한이 부족하거나, 목록에 없는 도구가 있거나, 크레딧이 부족하면 수동 승인을 유지한다.
- 목록에 없는 도구(향후 삭제·공유 도구 포함)는 설정과 무관하게 항상 수동 승인이다.
- 승인 기록에는 `approved_by=auto:user-setting`으로 남긴다.
- 화면에는 "자동 승인됨"과 되돌리기 안내를 보여 준다.
- `문서 편집·생성`을 켤 때 추가 확인창을 띄운다.

## 보류한 결정

삭제·외부 공유 자동 승인 토글은 만들지 않는다. 에이전트에 해당 도구가 없어서 토글을 켜도 아무 일도 일어나지 않고, 기능이 있는 것처럼 오해를 부르기 때문이다.

## 정할 것

- 에이전트에 삭제·외부 공유 도구를 추가할 때, 그 도구를 자동 승인 분류에 넣을지.
- 영구 삭제처럼 되돌릴 수 없는 작업은 분류를 두더라도 계속 수동 승인을 추천한다.

## 검토자 답변안

> 설정 > AI 에이전트 자동 승인에서 '폴더 정리(생성·이동·이름 변경)'와 '문서 편집·생성'을 분류별로 켜면, 해당 작업은 확인 없이 실행됩니다(기본값은 꺼짐). 자동 승인 여부는 서버가 실행 시점의 설정과 사용자의 실제 편집 권한으로 판단하며, 권한 검사를 건너뛰지 않고 승인 기록에 '자동 승인'으로 남깁니다. 경고가 있는 작업이나 분류에 없는 작업은 지금처럼 항상 사용자 승인을 받습니다. 현재 AI 에이전트에는 문서 삭제·외부 공유 기능이 없으며, 추가되더라도 항상 사용자 승인을 받습니다.
