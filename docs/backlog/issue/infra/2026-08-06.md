# 2026-08-06 Infra 이슈 — AWS 배포 준비 잔여 작업

로컬 구성은 Redis 추가·내부 포트 루프백 제한까지 완료(`docs/changelog/infra.md` 2026-08-06). AWS 배포를 위해 남은 작업. 기준: `docs/Fruition_AWS_MSA_Architecture.md`, `docs/backlog/Fruition_MSA_Proposal_revised.md` §7.

## 1. 메시지 큐 도입

- 비동기 ingest·변환이 아직 FastAPI BackgroundTasks(프로세스 내)로 실행됨 — 배포·재시작 시 작업 유실. SQS(이전 제안서) 또는 Kafka(현행 목표 문서) 채택 확정 후 worker 분리와 함께 도입. `docs/issue/ai/2026-08-06.md` 상호 참조.

## 2. IaC (Terraform)

- 저장소에 IaC 없음. VPC/ALB/ECS(또는 EKS)/RDS/ElastiCache/S3/Secrets Manager 프로비저닝을 Terraform plan·review·apply 절차로 관리(제안서 §7.2).

## 3. 관리형 서비스 매핑

- PostgreSQL → RDS, Redis → ElastiCache, MinIO → S3, 컨테이너 → ECR+ECS Fargate.
- 시크릿(`JWT_SECRET`, `INTERNAL_CALLBACK_TOKEN`, LLM API key, DB 자격증명)은 Secrets Manager로. `.env` 주입 방식 제거.

## 4. 배포 파이프라인

- CI에서 image build·test·ECR push, 단계 배포, DB migration은 배포 단계 별도 Job(제안서 §7.2). 현재 CI 없음.

## 5. 관측성

- OTel/ADOT·CloudWatch·X-Ray 계측 없음(제안서 §8.1). 배포 전 최소 metric·alarm 정의 필요.

관련: `docs/issue/backend/2026-08-06.md`, `docs/issue/ai/2026-08-06.md`.
