# 2026-07-21 Infra 이슈

## 1. llmPipeline 운영 접근 경계

- llmPipeline의 문서 입력 책임은 Backend로 일원화됐지만 FastAPI 직접 접근 자체는 차단되지 않는다.
- 운영 배포에서 llmPipeline을 private network에 두고 Backend에서만 접근하게 할지, 별도 서비스 인증을 추가할지 결정한다.
- Backend·AI 계약 배경은 `docs/spec/pipeline-db-ownership.md`, `docs/spec/chat-to-wiki-contract.md`를 참조한다.
