# 2026-07-25 Frontend 이슈

## 문서·workspace 휴지통 연동

### 필요한 작업

- 문서 삭제 요청에 `Idempotency-Key`와 JSON `base_version`을 전달한다.
- `GET /api/workspaces/{workspace_id}/documents/trash`에서 삭제 문서를 표시한다.
- 문서 복구 시 `POST /api/workspaces/{workspace_id}/documents/{document_id}/restore`에 `Idempotency-Key`와 `base_version`을 전달한다.
- 복구 응답의 `current_version`, `sort_order`를 반영하고 역할별 최상위 마지막에 표시한다.
- workspace 삭제·복구에는 `base_version`을 사용하지 않고 `Idempotency-Key`만 전달한다.
- `GET /api/workspaces/trash`에서 소유자가 삭제한 workspace를 표시한다.
- 삭제 workspace의 기존 문서·채팅·Wiki가 복구 후 다시 나타나도록 로컬 cache를 무효화한다.

### API 확인 위치

- `backend/src/main/java/fruition/document/dto/DocumentLifecycleRequest.java`
- `backend/src/main/java/fruition/document/dto/DocumentLifecycleResponse.java`
- `backend/src/main/java/fruition/document/dto/DocumentTrashResponse.java`
- `backend/src/main/java/fruition/workspace/dto/WorkspaceLifecycleResponse.java`
- `backend/src/main/java/fruition/workspace/dto/WorkspaceTrashResponse.java`

## Markdown 원문 내보내기 연동

### 필요한 작업

- 활성 workspace 멤버가 편집 가능한 문서에서 내보내기를 실행하면 `GET /api/workspaces/{workspace_id}/documents/{document_id}/export`를 호출한다.
- 응답의 `Content-Disposition`에 포함된 UTF-8 파일명을 사용해 `text/markdown` 본문을 `.md` 파일로 다운로드한다.
- 원본 자료와 휴지통 문서에서는 Markdown 내보내기 동작을 노출하지 않는다.
- 본문의 이미지 URL은 Markdown 문자열 그대로 내보낸다. 이미지 파일을 묶는 ZIP 내보내기는 자산 관리 후속 작업으로 처리한다.

### API 확인 위치

- `backend/src/main/java/fruition/document/controller/DocumentController.java` — `GET /{document_id}/export`
- `backend/src/main/java/fruition/document/dto/DocumentExportResult.java`
