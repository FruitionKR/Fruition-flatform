# 2026-07-27 AI/Pipeline 이슈

## 재편입 후 Concept 본문 의미 정합성 복구

문서 재편입 실행별 기여분 저장과 lint 구조 정리는 구현했다. 최신 재편입에서
사라진 active cluster claim·relation 후보, 문서-concept 연결과 materialized
relation은 `POST /wiki/maintenance/lint`의 `dry_run=false` 실행으로 정리할
수 있고, 최신 재편입이나 다른 활성 문서가 지지하는 내용은 유지한다.

남은 작업은 수정·삭제된 block을 근거로 이미 작성된 Concept 본문의 정의와
Evidence 문장을 최신 기여분에 맞게 다시 구성하는 것이다. 수정 block은 기존과
같은 `block_id`를 유지하므로 단순 문자열 삭제로 처리하면 최신 문장까지 지울 수
있다.

### 필요한 작업

- 활성 문서별 최신 기여분과 현재 Concept 본문을 입력으로 받는 의미 정합성 생성
  단계를 정의한다.
- 무효화된 source ref가 들어 있는 기존 문장과 최신 문서 기여 문장을 구분한다.
- 여러 문서의 활성 기여분을 합쳐 Concept 정의·Evidence·관련 개념을 재작성한다.
- 재작성된 Concept Markdown과 embedding unit을 같은 트랜잭션 경계에서 갱신한다.
- dry-run에서는 변경 후보와 근거만 반환하고 Wiki 본문과 embedding을 수정하지
  않는다.

### 완료 조건

- 수정된 block의 이전 주장은 사라지고 최신 주장만 Concept 본문에 남는다.
- 삭제된 block만 지지하던 문장은 제거된다.
- 다른 문서가 지지하는 문장과 relation은 유지된다.
- lint 재실행 결과가 동일하며 중복 문장이나 중복 relation이 생기지 않는다.
