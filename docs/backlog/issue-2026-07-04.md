# 2026-07-04 이슈

## 프론트엔드 후속 작업: wiki API가 workspace 경로 기반으로 변경됨 (breaking change)

### 배경

오늘 백엔드에서 wiki 조회를 workspace 단위로 격리했다(Scope B). 기존에는 `WikiController`가 `/api/wiki`에서 `wikiPageRepository.findAll()`로 **전 workspace의 wiki 페이지를 반환**해, 다른 사용자의 wiki가 그대로 노출되던 상태였다. 이를 문서·채팅 API와 동일한 경로 규약(`/api/workspaces/{workspace_id}/...`)으로 옮기고 인증·소유권 검증을 적용했다.

상세 변경 내용은 `docs/changelog/backend.md`의 2026-07-04 "feat: wiki 조회를 workspace 경로 기반으로 격리 (Scope B)" 항목을 참고한다. 커밋: `ae28f5a`.

### 변경된 API 계약 (프론트 수정 필요)

`WikiController`(`backend/src/main/java/fruition/wiki/controller/WikiController.java`) 기준.

| 기능 | 기존 경로 | 새 경로 |
|---|---|---|
| Wiki 그래프 조회 | `GET /api/wiki/graph` | `GET /api/workspaces/{workspace_id}/wiki/graph` |
| Wiki 페이지 상세 | `GET /api/wiki/pages/{wiki_page_id}` | `GET /api/workspaces/{workspace_id}/wiki/pages/{wiki_page_id}` |
| Wiki 페이지 rename | `PATCH /api/wiki/pages/{wiki_page_id}/rename` | `PATCH /api/workspaces/{workspace_id}/wiki/pages/{wiki_page_id}/rename` |

동작 변화(라이브 e2e로 확인):

- 옛 경로 `/api/wiki/*`는 이제 매핑이 없어 **404**.
- 새 경로는 `/api/workspaces/**` 규칙에 걸려 **인증 필수** — `Authorization` 헤더 없으면 **401**.
- 응답은 요청 경로의 `{workspace_id}` 것만 반환한다. 다른 workspace의 `wiki_page_id`로 상세를 요청하면 **404**.

### 프론트엔드가 해야 할 일

1. `frontend/app/_lib/api.ts`의 wiki 호출 경로를 위 표대로 workspace-scoped 경로로 수정한다(`fetchBackendData()`의 `/api/wiki/graph`, 페이지 상세/ rename 호출 포함).
2. 위 호출에 현재 선택된 `workspace_id`를 경로에 넣고, `Authorization: Bearer <access_token>` 헤더를 붙인다.
3. 401(미인증)/404(다른 workspace 또는 없는 페이지) 응답에 대한 처리를 추가한다.
4. wiki page id는 opaque UUID(`wiki_page_{uuid}`)이므로 id에서 `source:`/`concept:` prefix를 파싱하지 않는다. 이 항목은 이미 `docs/backlog/issue-2026-07-02.md`의 "Frontend 후속 작업 > F5. UUID wiki page id를 전제로 한다"에 정리돼 있으니 그대로 따른다.

### 선행 조건 (아직 프론트에 없음)

위 작업은 프론트에 **workspace 선택 상태와 토큰 저장/첨부 로직**이 있어야 가능하다. 현재 프론트에는 둘 다 없다. 관련 선행 작업은 아래 문서에 이미 정리돼 있다.

- `docs/backlog/issue-2026-07-03.md` — "프론트엔드가 workspace-scoped API로 마이그레이션 필요" (문서/질의/채팅 경로 마이그레이션, `Authorization`/`workspace_id` 부재).
  - 그 문서의 경로 표에서 `GET /api/wiki/graph` 행은 "유지될 가능성 높음(미확인)"으로 남아 있었는데, 오늘 변경으로 **wiki도 workspace-scoped로 이동**하는 것으로 확정됐다. 이 이슈 문서 기준으로 갱신한다.
- `docs/backlog/issue-2026-07-03.md` — "OAuth 로그인 후 code 교환 — 프론트엔드에서 구현해야 할 부분" (`/oauth/callback` 라우트, `POST /api/auth/oauth/exchange`, 토큰 저장).
