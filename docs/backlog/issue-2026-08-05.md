## `INTERNAL_CALLBACK_TOKEN` llmPipeline 양방향 적용

Backend가 호출하는 llmPipeline 업무 route에 `X-Internal-Token` 검증을 적용했습니다. `INTERNAL_CALLBACK_TOKEN` 미설정은 `503`, 헤더 누락·불일치는 `401`이며 `/health`는 인증에서 제외했습니다.

llmPipeline이 Backend로 보내는 진행 로그와 Query event callback에도 기존 작업 결과 callback과 같은 헤더를 추가했습니다.
