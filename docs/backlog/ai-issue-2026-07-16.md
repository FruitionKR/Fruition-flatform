# 2026-07-16 AI/Pipeline 이슈

## 완료 항목

- 일반 `POST /pipeline/runs`는 Backend가 먼저 생성한 `document_id`의 저장된 Markdown만 사용하도록 제한해 `content_hash NOT NULL` 책임 충돌을 해소했다.
- `/chat-wiki/runs`의 `input_markdown`은 기존 source page에 새 대화를 누적하는 입력으로 유지하고, Wiki 저장 범위는 기존 `documents` row에서 조회하도록 했다.
- 과거 `uq_wiki_pages_type_slug` constraint를 제거한 뒤 현행 workspace 단위 upsert로 같은 문서의 pipeline 재실행을 검증했다.
- Docling 중첩 group·`list_item` 순서를 보존하고 표·수식별 SLLM 사용 조건, Vision 거절 판정, evaluator 시간 기록을 개선했다.
- 처리 흐름과 PDF 실험 결과는 `docs/pdf-to-markdown-guide.md`에 기록했다.
- 제목·본문·표·수식·그림을 포함한 30페이지 전체 정확도 평가까지 완료했다.

## 확인 위치

- 입력 문서 책임: `llmPipeline/app/api.py`, `POST /pipeline/runs`, `POST /chat-wiki/runs`
- Wiki 저장: `llmPipeline/app/modules/wiki_ingestion/infrastructure/postgres_wiki_ingestion_repository.py`
- PDF 복원·평가: `docs/pdf-to-markdown-guide.md`
