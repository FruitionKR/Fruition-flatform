# Notion 가져오기: 폴더 대표 문서 정렬 보류

작성일: 2026-11-02. 결정을 미루고 현재 동작을 유지한다. 추적은 이슈 #90의 "F. 2026-11-02 결정을 미룬 UX 항목".

## 상황

- 하위 페이지가 있는 Notion 페이지는 `폴더 + 같은 이름의 대표 문서`로 가져온다(사용자 결정, 2026-11-02).
- 서버는 대표 문서를 `sort_order` 0으로 저장하고, 프론트 `importRunner`는 대표 문서를 먼저 생성한다.

## 문제

- 문서 트리는 이름순으로 정렬한다(`web/src/entities/tree/lib/projectsFromServerTree.ts`의 `byName`). `sort_order`는 쓰지 않는다.
- 그래서 대표 문서가 폴더 맨 위에 오지 않는다. 실제 시험에서 "02 프로젝트 진행" 대표 문서가 형제 문서 사이 5번째쯤에 놓였다.

의도한 트리(예시):

```text
02 프로젝트 진행/
├── 02 프로젝트 진행      ← 대표 문서
├── 01 기획
├── 02 설계
├── 03 개발
└── 04 회고
```

실제 트리(예시, 이름순):

```text
02 프로젝트 진행/
├── 01 기획
├── 02 설계
├── 02 프로젝트 진행      ← 대표 문서
├── 03 개발
└── 04 회고
```

## 선택지

- **A. 그대로 둔다 (현재 동작, 추천).** 이름순 정렬을 유지한다.
- **B. 폴더와 같은 이름의 문서를 항상 맨 앞에 둔다.** 앱 전체 정렬 규칙이 바뀌고, 사용자가 직접 만든 폴더에도 적용된다.
- **C. 트리 수동 순서 기능이 생기면 `sort_order`를 사용한다.** 가져올 때 저장한 0이 그대로 반영된다.
