# 2026-07-10 이슈 및 의사록

## Chat Wiki API 계약 확정

### 결정

- `/chat-wiki/runs`는 `document_id`와 `selection_mode`를 필수로 받는다.
- `document_id`는 source page 선택 key다.
- `input_markdown`은 기존 source page가 있는 `full` 누적에서만 허용한다.
  - `partial + input_markdown`은 API boundary에서 거부한다.
  - 기존 source page가 없는 최초 `full + input_markdown`도 거부한다.
  - 허용된 `input_markdown`은 backend가 이미 처리한 pair를 제외한 신규 pair Markdown이다.
- `partial`과 최초 `full`은 `document_id`로 저장된 Markdown을 읽는다.
- 기존 source page가 있는 `full`은 기존 source page markdown과 artifact를 context로 사용하고, source accumulation evaluator로 source page summary/key points/observations/categories를 보정한다.

### 검증

- API 계약 테스트에서 `input_markdown` 허용/거부 조건을 고정했다.
- 관련 `llmPipeline` 테스트 묶음이 통과했다.
- chat source accumulation payload 생성과 evaluator 결과 적용 로직을 `chat_source_accumulation.py`로 분리했다.
- review skill 기준 검토에서 기존 source page row 없이 artifact만 있는 경우 `input_markdown` 검증이 통과할 수 있는 문제를 발견해 수정했다.
