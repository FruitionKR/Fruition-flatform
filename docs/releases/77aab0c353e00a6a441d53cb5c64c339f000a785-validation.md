# 설정 릴리스 77aab0c353e00a6a441d53cb5c64c339f000a785 검토

## 범위

[PR #166](https://github.com/FruitionKR/Fruition-flatform/pull/166)의 KEDA embedding-server selector 변경이다. ingest·maintenance 작업자 실행도 기동 조건에 포함한다. 이전 성공 묶음은 a377209ef0d7ef2ac918aee26bc117704c9880ee다.

4개 서비스 main source와 5개 이미지 build 입력은 이전 묶음과 동일함을 읽기 전용으로 확인했다. publisher recipe에 KEDA 설정이 포함되어 새 릴리스 ID만 생기며 이미지·DB 스키마·비밀 변경은 없다. 게시 후 실제 release.json의 sources와 digest를 다시 비교해야 한다.

## 실제 수행한 검증

- 스케줄링 계약 테스트 12개, 이미지 게시 계약 테스트 24개, 배포 계약 테스트 56개 통과.
- 실제 AWS 렌더와 기존 성공 manifest를 대조해 변경은 embedding-server ScaledObject임을 확인했다. HPA는 저장된 고정 manifest에서 제외되는 기존 운영 정책이다.
- ingest와 maintenance의 minReplicaCount=0 및 실제 replicas=0 전환을 확인했다. 비용 추정과 cold start 잔여 위험은 [운영 검토](../embedding-worker-wake-review.md)에 적었다.
- [기존 복원 근거 #158](https://github.com/FruitionKR/Fruition-flatform/issues/158)를 참조한다. 동일 DB schema와 동일 이미지인 설정 변경이며 이번에 새로운 복원 시험을 수행했다고 주장하지 않는다.
- 배포 전 DB 스냅샷 available 확인, main CI 및 feedback 게이트 통과가 필요하다. 운영 smoke/PDF와 UI 시험은 배포 이후 수행할 예정이며 아직 완료된 기록이 아니다.
