# 랜딩 섹션 방문 기록·중복 메뉴 수정 배포 검토

- 프론트엔드 PR216·217: 내부 섹션 이동은 현재 방문 기록을 교체하고 로그인 이동은 기록을 추가한다. 상단 메뉴와 중복되던 알약 탭 및 전용 코드를 제거했다.
- 프론트엔드 소스 `d2616c2984926b4b470a79d4826d7d4bf6b46034`. 전체 테스트 1,537개·타입 검사·프로덕션 빌드 통과. 브라우저에서 네 섹션 이동 전후 history 길이 유지, 로그인→랜딩→이전 사이트 복귀, 중복 탭 제거를 검증했다.
- 이전 성공 릴리스 `45505a1fac4955bb9ee5f553a97fdc681540913a` 대비 프론트엔드 이미지만 변경한다. 게시 후 다른 네 서비스 digest와 백엔드·AI 소스 동일 여부를 대조한다. API·DB schema·migration·운영 설정 변경은 없다.
- 동일 schema의 기존 복원 시험 근거로 플랫폼 PR107을 재사용하며 새 DB 복원 시험을 수행했다고 주장하지 않는다.
- 기존 DB preflight·rollout·업무 및 PDF·AI smoke gate를 적용하고 운영 브라우저에서 방문 기록 누적 방지와 중복 탭 제거를 확인한다.
