# PDF 미리보기 수정 배포 검증

- 새 릴리스는 frontend 소스만 `40df69467e36bcd0882b94757db0da10065e1e04`로 변경한다. Access·Document·Pipeline·Converter 소스와 이미지 빌드 입력은 기존 `bc90ee595728f60defc3cf45517af33903ff4ddf`와 같다. DB migration은 없다.
- frontend PR #206/#207 및 main CI 39822908300 통과. 전체 프론트 테스트 1,542개와 프로덕션 빌드 통과. 로컬 프로덕션 빌드에서 실제 Chromium PDF iframe 요청이 CSP 위반 없이 완료됨을 확인했다.
- 운영 로그인 세션으로 읽기 전용 API 24개 검사 통과: 본인 문서 상세·원본 URL·blocks 200, 무인증 401, 서명 변조 401, 타 워크스페이스 및 다른 워크스페이스 실제 문서 ID 대입은 404. 문서 트리·위키 그래프·스킬·채팅 목록은 200. 인증 정보·문서 내용·서명 URL은 기록하지 않았다.
- 서버는 멤버십 확인 후 document ID와 workspace ID 및 삭제 여부를 함께 조회한다. PDF 임시 URL은 동일 검사 후 1시간 유효한 GET 주소로 발급한다. 이미 발급된 임시 주소의 유효기간과 권한 취소 반영 시점은 별도 설계 항목이며 이번 변경 범위에 포함하지 않는다.
- 운영 Deployment와 HPA는 모두 준비 상태였다. 의존성 검사에는 기존 운영 Low 6건과 개발 도구 High 5건, 빌드에는 기존 린트 경고 4건이 남아 있다. 이 기록은 모든 기능에 대한 무결함 보증이 아니다.
- 실제 새 버전 배포 후 업무 smoke 및 65MB PDF 업로드·Range·변환·AI 검증과 사용자 제보 PDF 화면을 다시 확인해야 한다.
