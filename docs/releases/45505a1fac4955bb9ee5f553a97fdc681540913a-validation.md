- 프론트엔드 PR214·215: 랜딩 내부 앵커를 Next.js Link로 통일해 로그인 후 뒤로가기 시 화면이 복원되도록 수정하고, 접근 코드 확인 전 간편 로그인 잠금 이유를 표시한다.

- 이전 성공 릴리스 `df7d4744f7c8d452e40d9b4b71a1c38ba46ca1c5`와 Access·Document·AI 소스가 동일하다. 프론트엔드 이미지만 변경하며 API 계약·DB schema·migration·운영 설정 변경은 없다. 게시 후 다른 네 서비스의 이미지 digest가 동일한지 대조한다.
