## 시험하지 않은 것과 위험

- **migration 실패 가능성**: 운영 데이터 규모의 잠금 대기는 시험하지 않았다.
  - V90 `ALTER TABLE documents ADD COLUMN`은 ACCESS EXCLUSIVE를 5s 안에 잡지 못하면 실패한다.
  - V91 CONCURRENTLY는 먼저 열린 트랜잭션이 끝나기를 최대 120s 기다린다. 실패하면 INVALID 인덱스가 남는다. 복구 절차는 SQL 주석에 있다.
- **복원 시험 범위**: RDS PITR와 스냅샷 복원은 시험하지 않았다. 배포 직전에 두 DB의 수동 스냅샷을 만든다.
- **rollback 불가**: schema가 바뀌므로 이전 이미지 rollback은 fingerprint gate에 막힌다. 문제가 생기면 앞으로 고쳐 나간다.
- **`user_upload_events` 테이블**: 하루 업로드 개수 한도를 없앤 뒤에도 expand-only 원칙에 따라 남겨 둔다. 새 코드는 이 테이블에 쓰지 않는다.

이 파일은 배포 성공 증명이 아니다. 배포 run의 preflight·migration·rollout·smoke 결과로 판단한다.
